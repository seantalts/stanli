## Current evidence gap and next experiment

Current main also contains the September 20 sampler startup and GQ/RNG
alignment. These can change trajectories without changing fixed-point
gradients. The retained timings predate both changes and the Stan 2.40 upgrade.
The local `deps/cmdstan/makefile` still identifies CmdStan 2.39.0; the current
vendored Stan headers identify 2.40.0. Existing build files alone do not certify
that the local executables contain current sources.

First establish matched current Release binaries and CmdStan 2.40, retaining
source/compiler/library identities. Recheck the original eight capped models
plus GEV, mixture theta, and cumulative ordinal before considering the full
31-model set. Preserve fixture/data/reference bytes and the original four-seed,
1000-warmup/1000-draw settings; retain all capped or failed seeds without
survivor averages. A cap pass is not a performance target, and the historical
0.8 ratio target is not adopted as a new requirement by this investigation.

Measure preparation, first and warm gradients, gradient-call/leapfrog counts,
output work, and peak memory separately. Compare numerical results at several
fixed points under existing policies, while recording ULP distances rather
than treating the scaled-error gate as a 10-ULP guarantee. Profile separately
from timing; confirm marginal results with counterbalanced repetitions and
identical-binary controls.

Start with GEV if its loop-executor hotspot survives. Use both Laplace models
and an unrelated ordinary model as controls for shared execution changes.
Mixture/negative-binomial sampling needs a separate trajectory and numerical
analysis. GEV's near-zero-shape expression also has independently demonstrated
precision loss shared with CmdStan; those synthetic points do not establish
that sampled chains visit the regime. Preserve upstream semantics and avoid
model-specific rewrites as a performance shortcut.
