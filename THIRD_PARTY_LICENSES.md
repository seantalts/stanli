# Third-party components in the stanli binary

The stanli shared library is self-contained: it links only the system C
and C++ runtimes, and everything else is compiled in. This file lists what
is compiled in and under what terms, because distributing the binary
distributes those components too.

| Component | Role in the binary | License |
| --- | --- | --- |
| [Stan math library](https://github.com/stan-dev/math) | every density, constraint transform, and reverse-mode derivative | BSD 3-Clause |
| [Stan](https://github.com/stan-dev/stan) | NUTS sampler and adaptation | BSD 3-Clause |
| [stanc3](https://github.com/stan-dev/stanc3) | the Stan compiler, compiled to a self-contained object and linked in | BSD 3-Clause |
| OCaml runtime | required by the compiled stanc3 object | LGPL 2.1 with the OCaml linking exception, which explicitly permits linking into a binary under other terms |
| [Eigen](https://eigen.tuxfamily.org) | dense linear algebra behind stan-math | MPL 2.0 |
| [Boost](https://www.boost.org) | math special functions and utilities used by stan-math | Boost Software License 1.0 |
| [SUNDIALS / CVODES](https://computing.llnl.gov/projects/sundials) | ODE integration for `integrate_ode_rk45` and `integrate_ode_bdf` | BSD 3-Clause |
| [nlohmann/json](https://github.com/nlohmann/json) | reading CmdStan-format JSON data | MIT |
| [walnutpie](https://github.com/flatironinstitute/walnuts) | WALNUTS sampler and its warmup adaptation | MIT |
| [{fmt}](https://github.com/fmtlib/fmt) | full-precision CSV formatting in the `stanli_run` CLI only | MIT |

Full license texts ship with the vendored sources fetched by
`deps/fetch.sh`; see `deps/math/LICENSE.md`, `deps/stan/LICENSE.md`, and
the license files under `deps/math/lib/`. walnutpie is vendored directly
in this repository, headers and license together, at
`runtime/third_party/walnutpie/`.
The CLI formatter is pinned to {fmt} 11.2.0; its license is in `deps/fmt/LICENSE`.

Notes on the two that carry conditions beyond attribution:

- **Eigen (MPL 2.0)** is a file-level copyleft: distributing the binary is
  fine, and modifications to Eigen's own files would have to be published.
  stanli does not modify Eigen.
- **OCaml runtime (LGPL 2.1)** ships with a linking exception written for
  exactly this case ("you may link this library into an executable and
  distribute that executable under terms of your choice"), so no relinking
  obligation attaches to the stanli binary.

Not in the binary, but in the repository: `tests/stanc3_good/overrides/`
holds Stan models copied from stanc3's test suite (BSD 3-Clause, the same
license as this repository), used as test inputs. The few runnable
adaptations are listed in `tests/stanc3_good/overrides.json`.

`tests/regressions/rbmi_mmrm.stan` is rbmi's MMRM model and
`tests/regressions/while_udf_slices.stan` contains two small functions from
it (Apache-2.0); the license text is in `tests/regressions/licenses/`.

Also in the repository, not in the binary: `tests/brms/` holds Stan models
and data written by brms 2.23.0 (GPL-2), used as test inputs. Parts of a
generated model are brms's own code, the `scale_r_cor` helper and the
inlined ordinal densities among them. `tools/gen_brms_models.R` regenerates
the directory from brms itself.

Also in the repository, not in the binary: `tests/cogmod/` holds Stan
models and data written by brms 2.23.0 against cogmod's custom families
(MIT), used as test inputs. A generated model's `functions {}` block
includes Stan code authored in cogmod for its custom density; see
`tests/cogmod/licenses/MIT`. `tools/gen_cogmod_models.R` regenerates the
directory from brms and cogmod.

Also in the repository, not in the binary: `tests/ctsem/` holds ctsem's
`inst/stan/ctsm.stan` (GPL-3), unmodified, with synthetic data generated by
`tools/gen_ctsem_data.R` (one entry uses the generator code from a Stan Forums
post by ctsem's author, https://discourse.mc-stan.org/t/41545), used as a test
input. The license text is
`tests/ctsem/licenses/GPL-3`.

Also in the repository, not in the binary: `tests/oncobayes2/` holds
OncoBayes2 0.10-0's `inst/stan/blrm_exnex.stan` (GPL (>= 3), Copyright (C)
2025 Novartis Pharma AG) with its one include inlined, and the data of the
package's three example models generated by `tools/gen_oncobayes2_data.R`,
used as test inputs. The license text is `tests/oncobayes2/licenses/GPL-3`.

Also in the repository, not in the binary: the directories below hold Stan
models from CRAN packages, with their `#include` lines inlined, and data built
by each package's own R functions through `tools/gen_<package>_data.R`, used
as test inputs. Each directory's `licenses/` holds the license text.

- `tests/rstanarm/`: rstanarm 2.32.2, GPL (>= 3), Copyright (C) 2015, 2016
  2017 Trustees of Columbia University. `continuous.stan` declares `CODOLS`
  without a body (rstanarm implements it in C++); the checked-in copy gives it
  a Stan body.
- `tests/multinma/`: multinma 0.9.1, GPL-3, by David M. Phillippo.
  `tests/multinma/unflattened/` holds one model and its include files
  unchanged.
- `tests/epinow2/`: EpiNow2 1.9.0, MIT, Copyright (c) 2020 EpiForecasts. The
  package's DESCRIPTION declares MIT. Its `inst/stan/include/license.stan`,
  copied verbatim at the top of each model, is the rstantools GPL-3
  boilerplate.
- `tests/mlumr/`: mlumr 0.2.0, GPL-3, by Ahmad Sofi-Mahmudi and Conor
  Chandler.
- `tests/rbioacc/`: rbioacc 1.3.1, MIT, Copyright (c) 2021 UMR5558 lbbe MEPS
  Aurélie Siberchicot. As with EpiNow2, the DESCRIPTION declares MIT and the
  `inst/stan/include/license.stan` copied at the top of the model is the
  rstantools GPL-3 boilerplate.
- `tests/beeguts/`: BeeGUTS 1.5.0, GPL-3, copyright Bayer AG and ibacon GmbH.
- `tests/hdbayes/`: hdbayes 0.2.0, MIT, Copyright (c) 2024 hdbayes authors.
- `tests/ecoensemble/`: EcoEnsemble 1.2.0, GPL (>= 3), by Michael A. Spence,
  James A. Martindale, Michael J. Thomson, Thomas I. J. Bartos and Luke E. K.
  Broadbent. The model has no `#include` and is copied as published.

Also in the repository, not in the binary: `tests/examplemodels/` holds 23
programs from stan-dev/example-models at commit `e5b7d9e2`, unchanged, with
their data. The repository's README places the examples under the new BSD
license unless a directory says otherwise; the `BPA/` directory carries
BSD-3-Clause, Copyright (c) 2016 Hiroki Itô, and `jupyter/sum-to-zero/` carries
BSD-3-Clause for its code, Copyright (c) 2018-2022 Stan Development Team and
their assignees. The license texts are in `tests/examplemodels/licenses/`.

Also in the repository, not in the binary: `tests/stanguide/` holds six code
blocks from the Stan User's Guide (stan-dev/docs at commit `b07b2a99`, whose
`LICENSE` puts the code under BSD-3-Clause, Copyright (c) 2018-2026 Stan
Development Team and their assignees, and the text under CC BY-ND 4.0). Only
code is used. `tools/gen_stanguide_models.py` extracts it, with the edits listed
in `tests/stanguide/README.md`. One data file is derived from the explosion
dates in the R package boot (License "Unlimited"). The BSD text is in
`tests/stanguide/licenses/`.

- `tests/hbayesdm/`: hBayesDM 2.0.1, GPL-3, by Woo-Young Ahn, Nate Haines and Lei Zhang with contributions from Jinwoo Jeong, Harhim Park, Jaeyeong Yang and Jethro Lee. The four models have no `#include` and are copied as published.

- `tests/bmgarch/`: bmgarch 2.1.0, GPL (>= 3), by Philippe Rast and Stephen Martin. The two models' `#include` lines are replaced by the text of the files they name; nothing else is edited.
