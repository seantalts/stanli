# Historical plans and reviews

This directory contains the former `docs/superpowers/` plans, specs and reviews,
plus the removed browser density-pack experiment. These records describe their
dated revisions; their task lists, “current” statuses, and instructions are not
current authorization. Start with the [research index](../README.md), not a
recursive read of this directory.

The longest completed records have been compacted into decision digests with
links to their full versions at commit `22cf0845bcd735e66f1e77e484a36f09657367aa`.
Use the actual immutable link in each digest for recovery; detailed result
records and raw artifacts elsewhere retain their original provenance.

The [catalog](../catalog.md) groups every plan, spec, review and result by topic.
